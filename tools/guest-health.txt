# What a guest kernel prints when its health fails: the boot tests fail a
# guest whose dmesg has a line with any of these before each reset
# (tools/linux/boot-test.sh, tools/macos/boot-test.py,
# tools/windows/boot-test.ps1). The guest kernel is upstream's CI kernel, Linux v6.1 (6.1.188);
# each pattern names the source that prints it. Every string either guest
# kernel has (strings of vmlinux-6.1.188, x86_64 and aarch64) that contains
# one of these is such a report, so a healthy guest prints none of them.
# Not every line with "WARNING:" in it: the kernel's own notices use the
# word, as x86's SRSO notice (arch/x86/kernel/cpu/bugs.c,
# srso_select_mitigation, printed under KVM too on an AMD host) and arm64's
# Spectre-BHB notice on unprivileged eBPF (arch/arm64/kernel/proton-pack.c,
# "WARNING: %s").
#
# Format, read the same way by every reader:
# - a line that is empty, or whose first character is '#', is a comment;
# - any other line is <arch><one space><pattern>: <arch> is all, x86_64 or
#   aarch64 (the guest's), and <pattern> is the rest of the line, a fixed
#   string (no regular expression), matched case-sensitively anywhere in a
#   dmesg line. A pattern is not empty, does not start or end with a space,
#   and has no tab and no single quote;
# - any other line is an error: the reader stops and names the line.
# A reader uses the lines of `all` and of its guest's arch.

all self-detected stall
